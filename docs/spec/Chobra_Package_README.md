# Chobra Комплект технического задания

Версия 1.0 от 25 октября 2026 года.

## Состав

- `Chobra_Full_Technical_Specification.docx` — оформленное техническое задание с навигацией, исходным логотипом и схемой арены.
- `Chobra_Full_Technical_Specification.md` — текстовая версия для разработки и ведения изменений.
- `Chobra_Design_Tokens.json` — цветовые токены, отступы, радиусы, типографика и параметры анимаций.
- `Chobra_Acceptance_Checklist.csv` — 75 критериев с полями для результата и свидетельства проверки.
- `Chobra_Process_Visualization.png` — схема арены и движения подтвержденных событий.
- `Chobra_Logo_Original.png` — неизмененная копия предоставленного логотипа.

## Использование

Основные требования находятся в ТЗ. Визуальная система описана в разделе 22, арена и анимации в разделе 23, приемка в разделе 31, этапы реализации в разделе 32. Дополнительные JSON контракты находятся в разделе 36.

Все файлы нужно держать в одной папке: Markdown ссылается на изображение схемы относительным путем. CSV сохранен в UTF-8 с BOM для открытия в Excel. Статус «Не проверено» в чек-листе относится к будущей реализации продукта.

Схема процесса является иллюстрацией визуальной механики; реальные значения и движение в приложении должны поступать из событий исполняемой среды согласно ТЗ.
