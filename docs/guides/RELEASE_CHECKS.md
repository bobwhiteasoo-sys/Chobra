# Проверка выпуска — 25 октября 2026

Проверенная среда: локальный macOS и серверный Docker по HTTPS.

- Серверные тесты: 174 существующих + 5 новых тестов Telegram.
- Новый QR-вход: проверены привязка к браузеру, срок действия, однократное потребление, отклонение, обновление кода, запрет групповых подтверждений, идентичность аккаунта бота и сайта.
- Браузер: 13 проверок, включая настоящий API (создание проекта и серии, арена, карточка нарушения, replay, сравнение и скачивание Markdown-отчёта).
- Интерфейс: проверены ширины 360, 390, 768, 1024, 1440 и 1920 пикселей; восстановление потока, дубликаты событий, переход по истории и reduced motion.
- Сборка Next.js и TypeScript: успешно.
- Production: отдельные службы web / api / worker / bot / PostgreSQL; миграции применены; бот зарегистрировал команды; HTTPS доступен; вход разработки отключён.
- Пользователь подтвердил успешный вход через настоящий Telegram-аккаунт.

## Что не следует утверждать

- Реальный платный вызов Anthropic не подтверждён: действующий ключ провайдера модели для этой проверки не предоставлен.
- Сценарный пример работает без ИИ. Результат сценарного теста не является результатом теста модели.
- Успешные проверки не означают отсутствие любых возможных ошибок, эксплуатационные гарантии или доказательство отсутствия всех лазеек.

## Обновление

Перед заменой были сохранены резервные копии исходников, базы и предыдущих Docker-образов. При переносе macOS-файлов обнаружены служебные AppleDouble-файлы; они исключены из сборки и переноса. Секреты не входят в Git и Docker-контекст.
